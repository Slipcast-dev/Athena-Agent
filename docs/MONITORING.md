# Мониторинг / Monitoring

| Раздел | Данные |
|---|---|
| Процессор / CPU | Общая нагрузка, user/system, логические ядра и история |
| Сеть / Network | Скорость приёма/передачи, интерфейсы, адреса, маршруты и DNS |
| Диск / Disk | Ёмкость, занятое/свободное место, приложения и их размеры, анализ папки |
| Память / Memory | Установленная/использованная память, давление, compression/swap, процессы и график |
| Аккумулятор / Battery | Доступные macOS сведения о заряде, состоянии, питании и износе |

Частота сборщиков: CPU/сеть/память — 1 с, процессы — 5 с, диск — 10 с,
батарея — 15 с, инвентаризация приложений — 300 с. Конкретная выборка может
задерживаться; интерфейс помечает устаревшие и недоступные данные.
Отсутствующее значение не отображается как измеренный ноль.

A single runtime coordinator serves active GUI subscriptions. Short history stays
bounded in RAM; monitoring data is not added to task history. Leases expire after
15 seconds without renewal. No MCP monitoring endpoint or new data permission is granted.

SSID/BSSID и публичный IP не запрашиваются. Мониторинг сети не создаёт запросов
геолокации и не отправляет сетевой трафик для определения адресов.
Поля аккумулятора и оборудования зависят от модели Mac и доступности системных API.
Отдельная ручная аппаратная приёмка остаётся открытой.
